# DeskProfiles UI polish

- Default window 980 × 770 (min height 580).
- Compact global shortcut bar above Saved monitor layouts. Recording guidance appears during recording.
- Desktop Items matrix sorts folder shortcuts first, then app/file shortcuts, then web shortcuts. Folder shortcuts show a folder emoji; real original Desktop folders remain in their existing section above the matrix.
- No changes to desktop folder redirection, switch handling, settings persistence or layouts.

Build on Windows with `dotnet build` from the project folder.
